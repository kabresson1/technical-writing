# Best Practices for Prompt Engineering

## About This Guide

This guide was created as part of my ongoing study of GenAI, prompt engineering, and AI-assisted workflows. It combines insights from professional learning resources, independent research, and hands-on experimentation with different AI models.

Several concepts covered in this guide, such as the use of prompt formulas, were explored further after taking a course on prompt engineering offered by the Project Management Institute (PMI). The guide also incorporates lessons learned from additional prompt engineering resources, technical articles, and research papers on prompting techniques and LLM reasoning.

This project aims to apply and evaluate prompt engineering concepts in practice by covering the following topics:

* An introduction to the prompt engineering process
* An overview of commonly used prompt frameworks
* Best practices for writing effective prompts
* A comparative experiment evaluating the RTF and CREATE formulas with two different AI models
